# Личная библиотека

Приложение для ведения персонального учета книг, контроля статусов чтения и хранения личных заметок.

* **Автор:** Степанова Ксения
* **Группа:** ФТ24ДР62ИС
* **Стек:** React, TypeScript, Vite, Node.js, Supabase, React Router
* **Версия Node.js:** 24.11.1

## Основной сценарий
Пользователь организует домашнюю полку книг и отслеживает прогресс чтения. Он может вносить названия книг, указывать обязательного автора текстом, выбирать жанр из справочника, ставить оценку от 1 до 5 и оставлять текстовые заметки. На итоговых этапах доступна фильтрация по статусу чтения/жанру и серверная статистика.


## Текущее состояние и доступные адреса (ЛР 2)
В рамках Лабораторной работы №2 в приложение добавлена полноценная многостраничная навигация без перезагрузки страниц (SPA) с помощью `react-router`.

**Доступные маршруты (URL):**
* `/` — автоматический редирект на список книг.
* `/books` — страница со списком книг (выведено 5 демонстрационных записей).
* `/books/:id` — страница подробной информации о книге, найденной по ID (например, `/books/b1`).
* `/books/new` — страница-заглушка для добавления новой книги.

**Что реализовано:**
* Описан строго типизированный интерфейс данных `Book` средствами TypeScript.
* Создана переиспользуемая карточка книги `BookCard` с отображением текстовых статусов на русском языке.
* Настроен общий макет приложения (`AppLayout`) с постоянной шапкой и навигационным меню.
* Добавлена кастомная обработка ошибок 404 (неизвестный путь) и ситуаций, когда книга с конкретным ID не найдена в массиве.

## Текущие ограничения
* **Данные:** Все записи о книгах сейчас являются демонстрационными (вымышленными) и хранятся локально в виде массива в коде приложения.
* **Формы:** Кнопки и страницы добавления книг представляют собой заглушки. Веб-формы, валидация полей и интерактивное сохранение будут реализованы в ЛР 3.
* **Бэкенд:** Авторизация пользователей, база данных Supabase и Node API на текущем этапе отсутствуют и будут подключены в последующих лабораторных работах.

# Личная библиотека

Приложение для ведения персонального учета книг, контроля статусов чтения и хранения личных заметок.

* **Автор:** Степанова Ксения
* **Группа:** ФТ24ДР62ИС
* **Стек:** React (v19), TypeScript, Vite, Node.js, Supabase, React Router
* **Версия Node.js:** 24.11.1

## Основной сценарий
Пользователь организует домашнюю полку книг и отслеживает прогресс чтения. Он может вносить названия книг, указывать обязательного автора текстом, выбирать жанр из справочника, ставить оценку от 1 до 5 и оставлять текстовые заметки. На итоговых этапах доступна фильтрация по статусу чтения/жанру и серверная статистика.

## Запуск
Все команды выполняются из корня скачанного проекта:
```bash
cd frontend
npm ci
npm run dev
```
После запуска откройте в браузере адрес, указанный в консоли (обычно `http://localhost:5173`).

## Проверка сборки
Для проверки корректности сборки и типов TypeScript остановите dev-сервер через `Ctrl + C` и выполните в папке `frontend`:
```bash
npm run build
npm run preview
```

## Текущее состояние и доступные действия (ЛР 3)
В рамках Лабораторной работы №3 приложение переведено на полноценный интерактивный режим работы с локальным CRUD-циклом без перезагрузки страниц (SPA).

**Доступные маршруты и действия:**
* `/` — автоматический редирект на список книг.
* `/books` — страница со списком книг (доступен локальный фильтр по статусу чтения и кнопка сброса фильтра).
* `/books/:id` — страница подробной информации о выбранной книге с возможностью удаления (через диалоговое окно подтверждения).
* `/books/new` — страница создания новой книги с использованием управляемой формы.
* `/books/:id/edit` — страница редактирования полей уже существующей книги через ту же переиспользуемую форму.

**Что реализовано:**
* **Общее состояние (Lift State Up):** Массив книг перенесен на верхний уровень в компонент `App.tsx`, что позволяет страницам синхронно видеть любые изменения, добавления или удаления.
* **Переиспользуемая форма (`BookForm`):** Создана единая форма для добавления и редактирования, работающая с изолированным черновиком (изменения не мутируют общий список до нажатия кнопки «Сохранить», а «Отмена» возвращает всё в исходный вид).
* **Предметная валидация:** Реализована проверка обязательных полей (название от 3 до 100 символов, автор, жанр), а также кастомное правило темы — для прочитанных книг обязательно должна быть выставлена оценка от 1 до 5 звезд.
* **Разделение пустых состояний:** Различаются экраны, когда на полке вообще нет ни одной книги, и когда книги отсутствуют только по выбранному фильтру.

## Текущие ограничения
* **Память приложения:** Все добавляемые, изменяемые и удаляемые данные живут исключительно в оперативной памяти открытого приложения. После обновления страницы (F5) или перезапуска сервера демонстрационный набор из 5 книг ЛР 2 восстанавливается.
* **Бэкенд:** Серверная авторизация пользователей, постоянное хранение в базе данных Supabase и Node API будут подключены в последующих лабораторных работах.
